# Security policy

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/dayanruben/agent-skills/security/advisories/new). Do not place credentials, payloads containing private data, or undisclosed vulnerability details in public issues. Include the affected skill, commit, relevant files, impact, and a minimal reproduction using synthetic data.

Review all skill content before installation or updates. Skills guide an agent that may access local files and external services; packaging validation does not establish safe behavior. Follow the target repository's instructions and the user's actual authorization.
