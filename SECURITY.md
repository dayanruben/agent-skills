# Security policy / Política de segurança

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/dayanruben/agent-skills/security/advisories/new). Do not place credentials, payloads containing private data, or undisclosed vulnerability details in public issues. Include the affected skill, commit, relevant files, impact, and a minimal reproduction using synthetic data.

Reporte vulnerabilidades pelo [canal privado de vulnerabilidades do GitHub](https://github.com/dayanruben/agent-skills/security/advisories/new). Não publique credenciais, payloads com dados privados nem detalhes de vulnerabilidades ainda não divulgadas em issues públicas. Inclua skill, commit, arquivos pertinentes, impacto e reprodução mínima com dados sintéticos.

Review all skill content before installation or updates. Skills guide an agent that may access local files and external services; packaging validation does not establish safe behavior. Follow the target repository's instructions and the user's actual authorization.

Revise todo o conteúdo antes de instalar ou atualizar uma skill. Skills orientam agentes que podem acessar arquivos locais e serviços externos; validar o empacotamento não comprova comportamento seguro. Siga as instruções do repositório de destino e a autorização real da pessoa usuária.
